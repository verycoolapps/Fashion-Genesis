# MODE A — RANDOM GENIUS (Random Invention)

## PURPOSE

Deliver a genuinely wild, highly distinctive fashion invention when the user asks for
something crazy, unexpected, "surprise me," "something nobody has ever seen," or gives
a chaotic constraint. The output still passes all quality gates — wild ≠ slop.


## PIPELINE OVERVIEW

```
SEED DRAW → FAST MUTATION PASS → 3 CANDIDATE SEEDS → PICK WINNER
    → FULL MUTATION ENGINE → MASTER FORMAT A–M → GATES → EVOLUTION VARIANTS
```

Time budget: fast pass ~20% of effort; full output ~80%. The seed stage exists
to prevent attachment to a weak first idea — never fall in love with seed #1.

## TRIGGERS

- "give me a crazy invention"
- "invent something unexpected"
- "surprise me"
- "something nobody has thought of"
- Single-word chaos: "chaos", "wild", "madness", "go crazy"
- User names a category but demands maximum weirdness within it

Do NOT use this mode when the user names a specific product goal — use
`product-innovation.md`. Do NOT use it for "a collection" — use
`collection-creation.md`.

## PHILOSOPHY

Randomness without anchoring produces decorative chaos. The method:

1. **Anchor on a real product problem.** Wildness lives in the mechanism and
   combination, not in abandoning function.
2. **Constrain the chaos.** Random picks give starting coordinates; the mutation
   engine then makes them coherent.
3. **Verify by synthesis.** Stage 6 kills any seed that is visually loud but
   functionally empty.

## STEP-B-Step PROCEDURE

### STEP 1 — Pick the random seed triple

Draw three independent random picks. State them openly before designing — the user
should see the game board.

**A. Product category** (pick one at random or via dice):
clothing · footwear · bag/carry system · headwear · eyewear · jewelry · watch/body
accessory · loungewear · outerwear · luggage · wearable tech · new/undefined category

**B. Foreign discipline** (the cross-industry source):
architecture · aerospace · automotive · robotics · biomimicry · furniture ·
neuroscience · sports science · marine/offshore · agriculture · digital/interaction ·
sculpture · mathematics · musical instruments · medical devices

**C. User archetype** (who the invention serves):
commuter · athlete · performer · caregiver · remote worker · traveler · elderly ·
child · medical patient · night-shift worker · creative professional · someone with a
disability · animal owner · festival-goer

If the user supplied one element (e.g. "insane shoes"), honor it and randomize the
other two.

### STEP 2 — Run the Impossible Idea Mutation Engine (fast pass)

Compress to one pass each, but do NOT skip stages:

1. **Assumption Destruction** — list 5 hidden conventions of that product category.
   Write them down. Example for footwear: shoes must be rigid-soled; laces/straps are
   the only adjustment; shoes are static once worn; upper and sole are separate
   layers; a shoe is a paired object.
2. **Cross-Industry Fusion** — take discipline B. Ask: what mechanism, structure,
   or principle from B could solve a real problem in the product or user C?
   Reject borrowings that are purely visual.
3. **Functional Mutation** — what different job could the product do? Movement
   assistance, storage, protection, communication, transformation, adaptation.
4. **Aesthetic Mutation** — one signature silhouette move: volume, fold, geometry,
   transparency, segmentation.
5. **Experience Mutation** — how does it open/adjust/transform/interact during use?
6. **Synthesis** — fuse the strongest 2–3 findings into ONE coherent invention.
   Kill anything that fails functional test.

### STEP 3 — Generate 3 candidate seeds

Produce three distinct inventions from the same seed triple. Each must differ in
CORE mechanism, not just color or trim:

- **Seed 1 — Literal fusion:** discipline B's mechanism applied directly to the product.
- **Seed 2 — Inverted assumption:** destroy the strongest convention found in Stage 1.
- **Seed 3 — User-first:** start from archetype C's worst daily friction and work backward.

One line each: name · one-line mechanism · why it's wild.

### STEP 4 — Pick the strongest seed

Score each seed on: functional novelty (does it DO something new?), mechanical
plausibility (could it physically exist?), user payoff (who benefits and how much?),
aesthetic distinctiveness (would it photograph as its own thing?).

Pick the highest total. State which seed won and why in one sentence. Do not
hedge or offer all three as equal — commit.

### STEP 5 — Full invention output

Run the winner through the complete Impossible Idea Mutation Engine (full pass now,
deeper than Step 2) and deliver Master Format sections A–M per SKILL.md §7.

Mandatory inside the output:
- Originality level (target 4–5 on the ladder) + 100-point score
- Mandatory Originality Audit (label PRELIMINARY if no research tools)
- Anti-Slop Gate pass (name the rejected decorative ideas)
- Human-Centered Safety check
- Gate 5: three evolution variants (Refined / Radical / Unexpected)

### STEP 6 — Offer next steps

Offer: deepen technical spec, generate the 10-view image set, expand into a
collection, or run commercialization.

---

## DECISION RULES

- If two seeds tie, pick the one with the stronger FUNCTION — aesthetics can be
  evolved; a weak mechanism can't.
- If the wildest seed fails safety or plausibility, do not ship it — pick second
  strongest and note what killed the winner.
- If the user's "crazy" request collides with safety (e.g. wearable blades),
  redirect the wildness into mechanism/aesthetic space and say so briefly.
- Never invent three products — this mode ships ONE hero invention (variants are
  allowed as Gate 5 evolution, not as separate products).

## MINI-EXAMPLE 1 — Seed draw → invention

**Draw:** category = bag · discipline = marine/offshore · user = commuter

**Stage 1 conventions (bags):** bags hang from shoulders; compartments are fixed;
water-resistance is a coating; bags are passive containers; opening requires hands.

**Stage 2 fusion:** marine = dry-bag pressure valves, buoyant closed-cell foam,
corrosion-proof hardware, ballast systems.

**Stage 3–5 mutations:** what if the bag doesn't just carry — it manages payload
weight distribution dynamically? What if it seals itself? What if it can be worn
multiple ways without straps?

**Synthesis → WINNER: "KEEL" — a commuter bag with an internal ballast chamber:**
a sealed bladder inside the pack that the user inflates/deflates via a valve to
tune carry comfort (firm = structured carry, soft = compressible for storage).
Marine-derived pressure-valve closure makes it fully submersible. Exterior uses
salt-resistant YKK Aquaguard zips and flotation-foam back panel that doubles as a
sit-pad. Originality Level 4. Score ~88. Functional story: commuters carry varying
loads (laptop day vs. gym day); KEEL re-profiles itself instead of forcing the
user to repack.

Rejected decoration during synthesis: carbon-fiber-look trim, glowing valve,
exposed "tech" seams — all slop.

## MINI-EXAMPLE 2 — Seed draw → invention

**Draw:** category = footwear · discipline = robotics · user = elderly

**Stage 1 conventions (shoes):** shoes are passive; sole is static cushioning;
laces are the only fit adjustment; shoes have no feedback; left/right are mirror
identical.

**Stage 2 fusion:** robotics = actuators, sensors, closed-loop control, gait
analysis.

**Stage 3–5:** what if a shoe could sense gait instability and actively correct it?
What if the shoe communicates fall-risk to a caregiver?

**Synthesis → WINNER: "STRIDE-SENTRY" — a shoe with a micro-actuated medial
counter:** embedded pressure sensors detect lateral sway; a small linear actuator
in the midsole counter-tightens the shoe's medial wall within 200ms of detecting
instability, giving a proprioceptive "handrail" effect. Companion app (optional)
logs fall-risk events for caregivers. Battery in removable heel insert. Originality
Level 4–5 (no mainstream product does active medial stabilization). Safety note:
actuator force capped below stumble-risk threshold; must be disclosed prominently.

Rejected: LED gait lights, holographic sole — slop.
