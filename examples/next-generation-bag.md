# NEXT-GENERATION BAG — Mode H: Full-Spectrum Invention

## A. Invention Reveal

**Name:** ORIGIN — a bag with no fixed opening, organized by an internal "skeleton" of tensioned rods that reshapes compartments based on contents.

**The one-sentence reveal:** A bag that doesn't have pockets — it has a **tensioned rod skeleton** that inflates, collapses, and reconfigures its internal compartments in real time based on what you put inside, creating a bag that is simultaneously a laptop sleeve, a gym bag, and a weekend duffel depending on its contents.

**The first image:** A person at an airport, holding what looks like a sleek black backpack. They drop a laptop inside — the bag's internal rods sense the rigid object and form a protective compartment around it. They add a water bottle — the rods shift, creating a cylindrical cavity. They add a jacket — the rods expand, creating a soft compartment. The bag is **organizing itself**.

**The 60-second reveal:** ORIGIN is a bag with no fixed internal structure. Instead, it contains **12 tensioned rods** — flexible carbon fiber or nitinol elements — arranged in a 3D grid inside the bag's shell. Each rod can be independently tensioned or relaxed by a micro-actuator system. When you put something inside, the bag's sensors detect the object's shape, size, and rigidity, and the rod network **reconfigures itself** to create an optimal compartment for that object. Put in a laptop → the rods form a rigid protective cavity. Put in a water bottle → the rods form a cylindrical sleeve. Put in clothes → the rods relax, creating open space. The bag's interior is **emergent**, not fixed.

**Why it feels new:** Every bag on the market has **fixed compartments** — a laptop sleeve, a water bottle pocket, a main compartment. ORIGIN has **no fixed compartments** — it has a **reconfigurable skeleton** that creates compartments on demand. It's not "a bag with pockets" — it's "a bag that organizes itself."

## B. Big Idea

**What's actually being invented:** A **reconfigurable container** that uses an internal tension network to create dynamic compartments based on contents, rather than fixed pockets.

The conceptual leap: bags are designed with **static internal geometry** — you decide where the laptop goes, where the bottle goes, where the clothes go. ORIGIN treats the interior as a **computational problem** — the bag's shape is the output of a tension distribution algorithm that optimizes for the current contents.

**Why this could matter:**

- **Space efficiency.** A bag that adapts to contents uses space more efficiently than a bag with fixed compartments. No wasted space in empty pockets.
- **Protection.** The rod network can create rigid cavities for fragile items (laptop, camera) and soft cavities for flexible items (clothes, documents).
- **Organization.** The bag's internal shape communicates where things are — you don't have to remember which pocket you put something in.
- **Versatility.** One bag replaces multiple specialized bags (laptop bag, gym bag, weekend bag) because it adapts to contents.

**The category it could create:** "Morphodynamic containers" — bags that reconfigure their internal geometry based on contents. Not "smart bags" (GPS, charging) and not "modular bags" (removable compartments). This is **emergent organization** — the bag's structure is a computed output, not a fixed design.

**Why now:** Three enabling technologies converged — flexible electronics for sensing, micro-actuators for tension control, and machine learning for shape optimization. The concept existed in research; the consumer product didn't.

## F. Functional Mechanism

### The Rod Network

The bag contains **12 nitinol rods** arranged in a 3D grid:

```
    [R1] [R2] [R3]
    [R4] [R5] [R6]
    [R7] [R8] [R9]
   [R10] [R11] [R12]
```

Each rod is a **shape-memory alloy** that can be tensioned or relaxed by a micro-servo motor. The rods are pre-tensioned to a neutral state — neither rigid nor floppy.

### Sensing System

8 pressure sensors distributed throughout the interior detect:
- **Contact pressure** — where objects are touching the interior
- **Distribution** — how objects are arranged
- **Changes** — when objects are added or removed

An IMU (inertial measurement unit) detects:
- **Motion** — walking, running, sitting
- **Orientation** — bag position (upright, sideways, upside down)

### Control Algorithm

The control system runs a **real-time optimization algorithm**:

1. **Sense:** Read pressure sensor data, IMU data.
2. **Classify:** Identify object types (laptop, bottle, clothes) based on shape/size.
3. **Optimize:** Calculate tension distribution that maximizes protection + organization + space.
4. **Actuate:** Adjust rod tensions to achieve target configuration.
5. **Verify:** Check that configuration matches intended compartments.

**Example: Adding a Laptop**

- Sensors detect a rigid rectangular object, ~35 × 25 × 2 cm.
- Algorithm classifies it as "laptop."
- Rods R1, R2, R4, R5, R7, R8 form a rigid cavity.
- Remaining rods relax, creating open space.
- Result: Protected laptop compartment + open main compartment.

### Biomechanical Honesty

The bag does NOT:
- Improve carrying comfort (it's not exoskeleton)
- Replace proper packing (it's a tool, not a shortcut)
- Work for all object types (it's optimized for common items)

It DOES:
- Reduce wasted space (no empty pockets)
- Improve organization (compartments match contents)
- Extend product lifespan (adapts to changing needs)
- Enable versatility (one bag, multiple functions)

## I. Manufacturing Strategy

### Prototype Phase (0–100 units)

- **Rod network:** Hand-assembled nitinol rods, off-the-shelf servos, custom PCB.
- **Shell:** Sourced from existing bag manufacturers, modified for rod access.
- **Assembly:** Manual, in a small workshop. Estimated 6 hours per unit.
- **Cost:** ~$500 per unit.

### Low-Volume Production (100–1,000 units)

- **Rod network:** Custom nitinol rods, automated servo assembly.
- **Shell:** Custom-woven polyester, automated cutting/sewing.
- **Electronics:** Custom PCB, automated assembly.
- **Cost:** ~$400 per unit.

### Mass Production (1,000+ units)

- **Rod network:** Injection-molded rod housings, automated assembly.
- **Shell:** Roll-to-roll manufacturing, automated cutting/laminating.
- **Electronics:** Custom ASIC, automated assembly.
- **Cost:** ~$300 per unit.

### Supply Chain

- **Nitinol:** Fort Wayne Metals (US), Johnson Matthey (UK).
- **Servos:** Dynamixel (Korea), Feetech (China).
- **Sensors:** FlexiForce (US), Tekscan (US).
- **Electronics:** Custom PCB, ARM Cortex-M4 (UK).
- **Shell materials:** Recycled polyester (global suppliers).

### Quality Control

- **Rod tension test:** 1,000 reconfiguration cycles per unit.
- **Sensor accuracy test:** ±5% pressure reading accuracy.
- **Water resistance test:** 10,000 mm hydrostatic head.
- **Durability test:** 10,000 flex cycles, 1,000 reconfigurations.
